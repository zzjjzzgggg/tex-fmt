\begin{itemize}
  \item 所有文件的命名尽量不要中英文混合（包括图片、tex、doc、以及其他乱器把早的
    各种各样的
    文件等），如果确实需要，在中英文之间加下划线或连字符。
  \item 所有 label 的取名不要用中文，用拼音或英文。
    \item \verb|\includegraphics|中不要加 figure 目录，也不要加文件后缀。
    例如，不要写成这样
    \verb|\includegraphics[width=.5\linewidth]{figure/myimg.png}|，写成这样
    \verb|\includegraphics[width=.5\linewidth]{myimg}|。
\end{itemize}
